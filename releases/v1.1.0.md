# PicShot v1.1.0

本次整合 v1.0.0 之后的功能与界面调整，统一发布为一个正式版本。

## 新增与改进

- **单实例运行**：同一 Windows 会话内重复启动会立即退出，不创建第二套界面和监听，避免多条截图绳和重复监听。
- **微信与 QQ 图片目录设置**：首次运行时，对尚未决定的配置显示提示；两项可分别提供或拒绝。选择后不再反复询问，也可稍后从设置中修改。仅监听用户提供的目录，不自动读取未授权的聊天目录。
- **集中设置入口**：右键屏幕左侧钉子，可访问截图、导入图片、添加监听目录、设置、图片收纳、检查更新、剪贴板收集开关和退出等操作。绳索空白处、袜夹不再承担右键设置功能。
- **统一外观**：左侧钉子采用小型矢量造型，与绳索、照片夹和袜夹使用一致的灰蓝色、描边和高光，不依赖额外的钉子 PNG 文件。
- **保留图片操作**：照片右键的复制、钉在桌面、打开、定位、保存副本和删除功能继续保留；右侧袜夹仍可左键打开分类收纳面板。
- **目录监听修正**：微信和 QQ 共用目录时，取消一项不会停掉另一项；取消聊天目录配置不会停掉默认下载目录监听。已监听目录可升级为递归监听。
- **边缘交互修正**：滚动到钉子或袜夹旁边时，被裁掉的照片区域不再接收图片拖拽等操作。
- **更新提示修正**：明确提示重启会清除尚未另存的临时截图。

## 图片规则与升级提醒

- 原有七天分类规则不变：最近七天的截图目录根层图片、下载目录图片和运行中的临时截图挂在绳上；截图子目录和其他目录的图片直接进入袜夹。
- 微信/QQ 配置用于纳入目录监听，不会让其他目录的图片绕过上述分类规则；这些图片可从袜夹中查找。
- 磁盘图片只记录原路径，不自动复制。原文件被移走或删除后不会继续显示旧副本；本次不改变此规则，也不恢复已经删除的原图。
- 程序内截图、剪贴板位图只保存在内存，退出或更新重启后不会恢复。有需要的临时截图请在升级前通过“保存副本”另存。
- 更新不会覆盖 `%LocalAppData%\FrameDock\data` 内的路径记录与配置。

## 下载与更新

- Windows 10/11 x64，需 .NET Framework 4.8。
- 下载 `PicShot-1.1.0-windows-x64.zip`，解压后运行 `app\PicShot.exe`，不要直接在压缩包内启动。
- v1.0.0 用户可重启程序触发更新检查，或从原截图绳菜单选择“检查更新”。升级到 v1.1.0 后，此入口集中在左侧钉子的右键菜单中。
- 检查更新需要能访问 GitHub；本版没有新增常驻后台推送服务。
