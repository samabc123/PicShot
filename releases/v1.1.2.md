# PicShot v1.1.2

本次将收纳篮、自建袜夹、截图与稳定性修复整合为正式更新。

## 收纳篮与自建袜夹

- 绳子最右侧改为装有袜子的收纳篮，入口周围仍为透明背景，只显示篮子、袜子与悬挂配件。
- 打开篮子先看到放大的命名袜子，每只袜子对应一个自建袜夹或原目录分类。点击查看图片，返回箭头回到篮子。
- 点击右上角加号新建袜夹，新分类会以袜子图案加入篮子；支持导入图片、重命名、移出分类及删除分类。
- 首页可按袜夹名称、图片文件名或原路径搜索；保留复制、拖拽、固定到绳上等图片操作。
- 同一图片可以加入多个袜夹，只记录原图路径和分类关系，不复制、移动或上传原图。删除袜夹不删除原文件。
- 自建袜夹保留原文件不可用的记录；原路径恢复后可重新读取。新导入图片直接归档，已有图片保留原来的绳上分类。

## 截图与常驻稳定性

- 修复区域截图黑屏：先获取屏幕快照，再显示选区遮罩，从未叠加遮罩的快照中裁剪。
- 修复剪贴板与目录监听重复收集同一截图的问题；不合并两个不同路径的原文件，不拦截用户主动进行的多次程序内截图。
- 常驻窗口不再主动抢焦点，Alt+F4 不会误关闭截图绳；退出仍通过左侧钉子菜单操作。
- 统一并清理右键菜单，改善文件删除、改名、暂时不可读和显示布局改变时的恢复行为。
- 临时图片采用 512 MiB 估算像素内存上限；达到上限时提示并停止继续收集，不自动删除已有图片或转存磁盘。
- 添加有界、轮换的本地异常日志，可能包含本地路径，不含截图像素，也不自动上传。不宣称所有退出原因均已消除。
- 左上角显示当前运行版本号；更新交接失败时恢复重试和“稍后”操作。

## 升级提醒

- 下载 `PicShot-1.1.2-windows-x64.zip`，解压后运行 `app\PicShot.exe`。支持 Windows 10/11 x64，需要 .NET Framework 4.8。
- v1.1.1 用户可通过启动检查、周期检查或左侧钉子菜单中的“检查更新”获取本版本。离线、程序关闭或 GitHub 无法访问时，不能保证收到通知。
- v1.1.0 及更早版本没有更新检查回退机制；检查失败时请从正式发布页手动下载。
- 升级会重启程序，尚未另存的内存临时截图不会恢复，请先按需另存。更新包不包含用户图片、路径记录或个人分类。
- 自建袜夹只是本地分类，不是加密保险箱；名称和原图路径以普通元数据保存。请保护原文件与 Windows 账户。
