# PicShot v1.1.1

本次集中修复更新检查和通知，并发布此前的图片固定与袜夹外观改进。

## 更新检查与通知

- GitHub API 限流、超时或不可用时，改查同一仓库的官方发布页。安装包仍必须通过大小、SHA-256 和包内版本校验，不跳过校验。
- 启动约 5 秒后首次检查，成功后每 4 小时再次检查；失败后按 1、5、15、60 分钟退避重试，后续每 60 分钟重试。
- 同一版本每次运行只自动提醒一次；选择“稍后”后，仍可右键左侧钉子选择“检查更新”重新打开提示。重启后会重新提醒。
- 手动检查与自动检查重叠时，不再丢失用户请求的结果提示。
- 退出时取消进行中的检查，忽略退出后的迟到响应；取消退出不会停掉后续检查。
- 更新窗口增加完整更新说明入口。
- 修正安装在盘符根目录时的更新目标路径；更新成功后若临时缓存清理失败，不再误触发程序文件回滚。

## 图片与外观

- 移除“钉在桌面”，改为“固定在绳上”。固定图片不受目录或七天期限限制，并优先悬挂；再次点击照片夹可取消固定并收回袜夹。
- “收回袜夹”只改变分类，不移动或删除原文件；“恢复自动分类”恢复原来的目录与七天规则。
- 手动分类随原路径记录保存，重启后恢复；临时截图仍只保留在内存中。
- 重新绘制袜夹入口，统一钉子与绳索配件样式。

## 旧版用户升级提醒

- v1.1.0 及更早版本能正常访问 GitHub API 时，重启或手动“检查更新”可以发现本版本。
- 若旧版遇到 API 限流或网络问题，自动检查可能没有提示，手动检查可能失败。请从本发布页下载 `PicShot-1.1.1-windows-x64.zip`，退出旧程序后解压并运行 `app\PicShot.exe`。不要直接在压缩包内运行。
- 旧程序不会因新版发布而被远程修补；升级后，后续检查才会使用新的回退与重试机制。程序关闭、离线或 GitHub 无法访问时，无法保证收到通知。
- 升级会重启程序，尚未另存的内存临时截图不会恢复；请先按需另存。原图、图片路径记录和设置不会因更新被覆盖，磁盘图片不自动存副本。
- Windows 10/11 x64，需要 .NET Framework 4.8。
