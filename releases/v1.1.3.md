# PicShot v1.1.3

本次将双击看图、右键菜单收起和截图绳候补规则整合为正式更新。

## 双击打开图片

- 截图绳和收纳篮中的图片支持双击打开，单击复制、拖拽取用仍然保留。
- 磁盘图片交给系统默认看图程序；临时截图直接在内存中预览，不为打开图片而写入副本。
- 关闭预览不会删除图片记录。预览是普通窗口，不恢复已经移除的桌面置顶功能。

## 菜单外部点击收起

- 右击照片后，点击软件外部区域会关闭菜单，并将截图绳和打开的收纳篮一起向上收回。
- 选择菜单命令不视作外部取消；正常鼠标移出仍保持约 0.8 秒，再执行收起动画。

## 手动固定与七天候补

- 手动固定的图片优先悬挂，不会因超过七天或自动容量限制而被自动收回袜夹。
- 自动悬挂只选择符合原目录规则、近七天新出现或更新的图片，按时间从新到旧填充一排剩余位置。
- 一排容量根据屏幕宽度计算。超量自动图片留在原目录袜夹中候补；绳上图片删除、移走、原文件失效或容量改变后，按相同规则重新补位。
- 超过七天的候补图片不再自动上绳，即使还有空位也一样；仍可手动固定。主动收回袜夹的图片不会自动补回。
- 截图目录根层、下载目录及本次运行的临时截图沿用原有自动分类规则；截图目录子文件夹及其他目录图片仍归入袜夹。
- 如果仅手动固定的图片就超过一排容量，全部保留并支持横向浏览，自动图片继续候补。自建袜夹的显式成员关系不被候补规则改写。
- 候补和固定只调整显示与路径元数据，不复制、移动或自动保存图片。原文件不可用时不读取旧副本；恢复原路径后可重新显示。

## 升级提醒

- 下载 `PicShot-1.1.3-windows-x64.zip`，解压后运行 `app\PicShot.exe`。支持 Windows 10/11 x64，需要 .NET Framework 4.8。
- 旧版可通过启动检查、周期检查或左侧钉子菜单的“检查更新”发现本版本。程序关闭、设备离线或 GitHub 无法访问时，不保证通知送达；检查失败时可从正式发布页手动下载。
- 升级会重启程序，尚未另存的内存临时截图不会恢复。手动固定也不会让临时截图在重启后恢复，请先按需另存。
- 更新包不包含用户图片、路径记录或个人分类，不覆盖 `%LocalAppData%\FrameDock\data`。自建袜夹仍只是本地分类，不是加密保险箱。
