# PicShot

PicShot 是一个面向 Windows 的截图与图片工作台。磁盘图片只记录原文件路径，不自动复制图片。

## 解决的问题

- 图片可以从任意文件夹导入，不依赖 Windows 的 Screenshots 文件夹。
- 添加文件夹后会持续监听新图片；原文件不可用时，图片会从截图绳上隐藏，原路径恢复后可以重新显示。
- 导入图片、监听文件夹和剪贴板文件列表只引用原文件，不创建本地副本。移动或删除原文件后，PicShot 不会从旧副本继续读取。
- `%LocalAppData%\FrameDock\data\state.json` 保存原文件路径、监听目录等记录，不保存图片内容。原文件仍可访问时，重启后才会恢复显示。
- 程序内截图和剪贴板位图只保存在运行时内存中，不自动写入图片文件；关闭程序后不会恢复。需要长期保留时，请主动使用“保存副本”并选择位置。
- 从绳上右键菜单正常退出会先保存路径记录；若保存失败，会提示并允许取消退出。强制结束进程无法保证本次新增路径记录保存成功。
- 截图绳优先显示最近 7 天内新出现或更新的截图目录、下载目录图片，以及本次运行的临时截图；超过 7 天后自动进入右侧袜夹。绳上图片多时可用鼠标滚轮横向浏览，不因数量多而提前归档。其他已记录的图片也在袜夹中，按原文件夹分类并可搜索、继续浏览。袜夹不会移动或复制原图；临时截图即使进入袜夹，关闭程序后仍会消失。截图目录会监听子目录，下载目录由系统定位并监听顶层文件；其他目录可手动添加监听。

## 构建和运行

需要 Windows 10/11 与 .NET Framework 4.8：

```powershell
.\build.ps1
.\build\PicShot.exe
```

构建产物位于 `build\PicShot.exe`。程序启动后会在屏幕顶部显示一条收起的截图栏。鼠标移到屏幕顶部时展开，鼠标离开后自动收起；单击图片复制，拖拽图片到其他程序取用，点击“钉”可以打开可移动的桌面置顶参考图窗口。最右侧的袜夹打开按目录分组的收纳面板，单击图片复制、拖拽取用、右键可钉图或打开原文件。绳上图片右上角的“×”及收纳面板的删除操作都会删除对应原文件（临时截图只移除）；删除原文件前会显示路径并要求确认，失败时保留图片记录。旧版自动创建的副本不再作为原文件的回退来源；旧版剪贴板图片可能以 `library` 内的文件作为原件，仍会按已有路径显示，删除该图片也会删除此文件。旧 `library` 文件不会自动清理，以免误删唯一的图片。从旧版升级时，若状态中仍有副本路径，会先校验并保留 `state.json.legacy` 元数据快照；旧状态有变化时保留带时间戳的新快照。无法完成备份则停止启动，避免覆盖旧路径记录。快照不含图片内容。

## 当前版本

这是一版可运行的基础版本，已经覆盖顶部截图栏、截图、导入、目录监听、路径记录、缩略图、复制、拖拽、打开、定位、另存和置顶预览。标注编辑、文字收集、全局快捷键和多显示器截图还可以在此资源库模型上继续补充。
